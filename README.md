# absensi-pkl
Ini adalah sistem absensi pkl yang terhubung dengan google script sebagai backend

## Tampilan
- Font Bricolage Grotesque dan Public Sans disimpan di folder `fonts/` (tidak memanggil Google Fonts, Tailwind lagi).
- Grafik masih memakai ECharts dari CDN jsdelivr.
- Di desktop menu guru ada di sisi kiri; di ponsel menjadi bar di bawah layar.
